## Connected commerce workflows

OJGroceries is a full-stack e-commerce application built with ASP.NET MVC. It combines authentication with product, order and user workflows, backed by SQL Server.

The project connects the pages people use to backend application logic and relational persistence. It is part of my work exploring how interfaces, business workflows and database models fit together.
