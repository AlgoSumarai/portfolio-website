## Learning through game interaction

SnakeAI explores reinforcement learning through an AI-controlled Snake game. Built with Python and PyTorch, it connects game state, actions and repeated training interactions.

## State, memory and training

The project brings together state encoding, replay memory and a training loop. These components connect what the agent observes in the game to the experience used during learning.

The opening image is a frame from the repository's recorded demonstration. The remaining visuals explain the project's learning components; they are diagrams rather than additional screenshots.
